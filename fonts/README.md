# Bundled fonts

Venu embeds the variable Geist and Geist Mono TrueType fonts from the Google
Fonts repository's OFL directories. The exact source URLs, byte lengths, and
SHA-256 hashes are recorded in [SOURCE.json](SOURCE.json). The matching SIL Open
Font Licenses are included beside the files. Font files are loaded from memory
by DirectWrite and egui; Venu does not install them into Windows.
